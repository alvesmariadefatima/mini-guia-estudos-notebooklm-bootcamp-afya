# 📘 Mini Guia de Estudos

## Resumo Estruturado

### O que é Inteligência Artificial?

É uma área da computação que desenvolve sistemas capazes de realizar tarefas que normalmente exigiriam inteligência humana.

### Machine Learning

Permite que máquinas aprendam padrões a partir de dados sem programação explícita para cada situação.

### Deep Learning

Utiliza redes neurais profundas para resolver problemas complexos como visão computacional e processamento de linguagem natural.

### IA Generativa

Capaz de criar conteúdos inéditos como textos, imagens, códigos, áudios e vídeos.

### Large Language Models (LLMs)

Modelos treinados com grandes volumes de texto para compreender e gerar linguagem natural.

### Agentes Inteligentes

Sistemas capazes de perceber, raciocinar, planejar e executar ações para atingir objetivos específicos.
